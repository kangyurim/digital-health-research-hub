# Research Hub · 디지털전략운영실

국책과제 통합 모니터링 시스템의 1차 구현입니다.

- 전체 과제 검색 및 팀·상태·중점 과제 필터
- 과제 요약, 기본 협약, 수행 기록·캘린더, 예산, 인력, 문서의 6개 상세 탭
- 수동 등록·수정 및 날짜별 기록 보존
- 승인·반영 예산 변경, 비목 간 이동, 현금·현물 구분, 집행 예정 집계
- D1 계정별 영구 저장, 수정 버전 충돌 감지, R2 파일 업로드·다운로드
- JSON 데이터 내보내기 (첨부 파일은 개별 다운로드)

처음 표시되는 12개 과제는 가상 예시입니다. 설정에서 예시 과제만 정리하고 실제 자료를 입력할 수 있습니다. 로컬 테스트 데이터는 배포에 포함하지 않습니다.

## 운영 범위

현재 소유자 전용 비공개 Sites로 운영합니다. 계정마다 데이터가 분리됩니다. 조직 공동 데이터, 팀별 조회·수정 권한, 팀장 확인 절차, 조직 로그인 연계는 운영 정책 확정 후 별도 구현해야 합니다. 전자결재는 외부 기존 시스템에서 수행하며 이 사이트에는 처리 상태를 수동 기록합니다. 엑셀/PPT 자동 추출과 개인별 맞춤 화면은 후속 범위입니다.

금액은 원 단위로 저장하고 화면에서 백만원 단위로 표시합니다. 당해연도 예산은 최초 배정액과 승인·반영 증감액의 합계입니다. 잔액에서 집행 예정액을 차감하지 않습니다. 예산이 0이면 집행률을 산정하지 않습니다.

## 개발

Node.js 22.13 이상이 필요합니다. 프로젝트는 Sites의 Vinext starter와 build integration을 사용합니다. `npm run dev`로 로컬 미리보기를 실행하고 `npm run db:generate`로 스키마 마이그레이션을 생성합니다. `.openai/hosting.json`에 D1 `DB`, R2 `BUCKET` 바인딩을 선언했습니다. 사이트 배포는 Sites 스킬의 소스 동기화 및 배포 절차를 따릅니다.

## 검증

TypeScript 검사와 프로덕션 빌드, 예산 승인/대기/이동/집행 예정/현금·현물/0원 계산, 저장·재조회, 버전 충돌, 비인증 요청 차단, 잘못된 예산 검증, 파일 업로드·다운로드 및 계정별 파일 접근을 점검했습니다. 데스크톱과 390px 모바일 화면, 브라우저 수행 기록 입력·저장을 확인했습니다.
